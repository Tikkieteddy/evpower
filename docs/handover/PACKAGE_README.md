# EV Project Handover Package

1. Extract the ZIP beside a clean clone of the repository, or open files directly from the package.
2. Start with `START_HERE_CLAUDE.md`, then `CLAUDE.md`, `HANDOVER.md`, and `DOCUMENT_INDEX.md`.
3. Open `docs/handover/HANDOVER_DASHBOARD.html` in a modern browser; no server is required.
4. Use `docs/handover/HANDOVER_SUMMARY.pdf` for formal review/printing.
5. Verify all statements against the current source before editing; the audit baseline is commit `5360d94` on 2026-10-28.

The ZIP contains handover documents, diagrams, wireframes, and report artifacts only. It excludes source code, secrets, `node_modules`, `dist`, and Vercel local metadata.
